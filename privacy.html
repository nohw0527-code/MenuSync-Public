MenuSync Connector 개인정보처리방침

시행일: 2026-09-05

MenuSync Connector는 배민, 쿠팡이츠, 요기요 사장님센터의 로그인 연결 상태를 사용자의 Chrome에서 확인하는 확장프로그램입니다.

1. 수집하지 않는 정보

현재 버전은 배달앱 ID 및 비밀번호, 결제정보, 실제 리뷰 내용, 메뉴 데이터 또는 그 밖의 개인정보를 수집하지 않습니다.

2. 쿠키 접근 및 처리

Chrome cookies API를 사용하여 지정된 사장님센터 도메인에 필요한 인증 쿠키가 존재하고 만료되지 않았는지만 확인합니다.

  • 쿠키 값을 화면에 표시하지 않습니다.
  • 쿠키 값을 로그에 기록하지 않습니다.
  • 쿠키 값을 파일이나 Chrome 저장소에 저장하지 않습니다.
  • 쿠키 값을 외부 서버 또는 제3자에게 전송하지 않습니다.

3. 로컬 저장소

chrome.storage.local에는 마지막 연결 상태 확인 시각 등 비민감 로컬 상태만 저장합니다. 인증 쿠키 값, ID 및 비밀번호, 토큰 원문은 저장하지 않습니다.

4. 사이트 접근 권한

로그인 상태 확인에 필요한 인증 쿠키의 존재 여부를 읽기 위해 다음 범위만 사용합니다.

  • https://*.baemin.com/*
  • https://*.coupangeats.com/*
  • http://*.coupangeats.com/*
  • https://*.yogiyo.co.kr/*
  • http://*.yogiyo.co.kr/*

쿠팡이츠와 요기요의 HTTP 권한은 로그인 상태 판정에 필요한 일부 쿠키가 non-Secure 형태로 저장되기 때문에 필요합니다. 전체 사이트 권한은 사용하지 않으며, HTTP 권한을 네트워크 요청에 사용하지 않습니다.

5. 현재 제공하지 않는 기능

현재 버전에는 자동 로그인, 외부 MenuSync 서버 통신, 메뉴 또는 리뷰 변경 기능, Gemini·AI 기능, 예약 기능이 없습니다.

6. 제3자 제공 및 판매

사용자 데이터를 판매하지 않습니다. 인증 쿠키 값을 제3자에게 제공하지 않으며 광고, 분석 또는 추적 목적의 데이터 수집이나 외부 전송을 하지 않습니다.

7. 데이터 보관 및 삭제

인증 쿠키 값을 저장하거나 서버로 전송하지 않으므로 해당 값의 서버 보관기간은 없습니다. 확장프로그램이 저장한 비민감 로컬 상태는 확장프로그램 삭제 시 Chrome의 확장프로그램 로컬 데이터 처리에 따라 함께 제거될 수 있습니다.

8. 보안

필요한 인증 상태는 Chrome Extension API를 통해 사용자의 기기 안에서만 확인하며, 외부 JavaScript, 광고, 분석 도구 또는 추적 스크립트를 사용하지 않습니다.

9. 문의

개인정보 처리와 확장프로그램에 관한 문의는 개발자 GitHub 프로필을 통해 접수할 수 있습니다.

10. 변경

향후 데이터 처리 범위가 변경되는 경우 기능 배포 전에 본 개인정보처리방침과 Chrome Web Store 개인정보 공개 항목을 갱신합니다.
